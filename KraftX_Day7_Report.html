Section 1

Executive Summary

Day 7 was focused on elevating the platform from a functional prototype to a polished, production-grade B2B/B2C e-commerce experience. The session addressed critical UX problems across the entire shopping journey — from product discovery and the cart to checkout routing and post-purchase review collection.

Major architectural additions include a conditional checkout router (cart threshold logic), a real customer review system with photo uploads, a site-wide global footer, and a full product detail page (PDP) redesign incorporating similar products, breadcrumbs, and social proof.

Section 4

Bugs Found & Resolved

  • Wrong page on "My Cart" click: Cart Navbar button was pointing to /contact?mode=inquiry instead of /cart. Fixed.
  • T-shirt shown on gift set PDP: Product Detail Page had hardcoded "Basic T-Shirt" content regardless of which product was clicked. Replaced with dynamic data from shared products catalogue.
  • T-shirt thumbnails on gift set PDP: Thumbnail strip was using a hardcoded array of t-shirt model photos. Now dynamically renders same-category product images.
  • Footer hydration crash: Footer.tsx used onMouseEnter/onMouseLeave event handlers without "use client" directive, causing a Next.js runtime error. Fixed.
  • Random images (Nike shoes, Bitcoin): Products had leftover Unsplash placeholder images from the initial design phase that were completely unrelated to corporate gifts. Replaced with contextually relevant images.
  • Fake reviews displayed: Three hardcoded fabricated reviews were being shown. Removed completely. Replaced with a real user-submitted review system.

Section 6

Recommended Next Steps

  1. Backend Review API: Currently reviews are stored in localStorage per browser. For production, implement a Prisma Review model and a POST /api/reviews route so reviews persist across devices and are user-verified.
  2. Real Checkout Integration: The /checkout page is currently a UI stub. Integrate Razorpay order creation and webhook handling to complete the B2C payment lifecycle.
  3. Mockup Set Completion: Only the round-neck front mockup has been updated. Replace round_back.png, vneck.png, vneck_back.png, polo.png, and polo_back.png with matching high-quality images for visual consistency in the Design Studio.
  4. Product Image Consistency: The corporate gift products currently use generic Unsplash images. These should be replaced with actual catalogue photography from the client's physical catalogue once available.
  5. Cart Persistence: The cart currently resets on page refresh. Consider persisting cart state to localStorage or a backend session so users don't lose their selections on navigation.
  6. Order Confirmation Emails: After /checkout is completed, trigger a Nodemailer email confirmation to the customer with an order summary and reference number.
